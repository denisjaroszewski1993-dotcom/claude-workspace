# Aktien

Notizen zu Denis' Aktien auf Trade Republic und zu Werten, die beobachtet werden.

- `watchlist.md`: Werte, die beobachtet werden, mit Einstiegszonen und Terminen.
- `trades.md`: Log der Käufe und Verkäufe.
- `weltraum-aktien.md`: Recherche zu börsennotierten Weltraum-Firmen und Zulieferern in Deutschland und Europa.
- `gespraechsverlauf.md`: verdichtete Zusammenfassung der Sitzungen.
- `berichte/`: tägliche Kursberichte, ein File pro Tag.

Der tägliche Bericht läuft über den Skill `aktien-update` (`.claude/skills/aktien-update/SKILL.md`).
Zeitplan: werktags 07:50 Uhr (Europe/Berlin), Push und E-Mail an Denis. Auf Zuruf: „Aktien-Update“.
